Webhook amoCRM

Отслеживаются создание, обычное изменение, смена статуса и ответственного. amoCRM получает HTTP 200 даже при внутренней ошибке, поэтому webhook не отключится.

Логика отправки

Строгий режим не перепутает SaleBot ID с VK ID. Проверка только через API слабее: числовые пространства могут пересекаться.
Защита от дублей включена всегда: одинаковый снимок сделки повторно не вызывает callback. Ошибки повторяются автоматически до 5 раз и остаются в журнале.
