Управление потоками

Рабочий адрес: https://junior.sobakovod.pro/streams/. Для входа используется личная учётная запись Nexus; одного имени сотрудника недостаточно.

Потоки

  • Поток активируется только после появления VK- и Telegram-ссылок в таблице ссылок.
  • Учитель и дата берутся из операции создания чатов.
  • Новые подходящие оплаченные заказы назначаются в последний активный поток курса.
  • Клиент без покупки может быть найден виджетом по точной почте или телефону. После подтверждённой ручной выдачи тарифа Nexus добавляет его в Streams и, если есть готовый поток, в учебную таблицу.

Google Sheets

Таблица учеников является зеркалом Nexus. Ручные изменения строк восстанавливаются. Обратно импортируются только чекбоксы уроков.

Перенос

GetCourse обновляется, ссылки отправляются через доступный канал, затем ученик удаляется из управляемых старых чатов. Неуправляемая VK-беседа пропускается без попытки удаления.

Тестовый период

В карточке ученика и в виджетах сообщений кнопка «Тестовый период» выдаёт курс «Щенок», «Собака» или оба на 1–90 дней. До выдачи Nexus проверяет GetCourse ID, почту, телефон и группу «Использовал тестовый период».

  • Начало и окончание сохраняются как абсолютное UTC-время в SQLite; перезапуск Nexus не продлевает срок.
  • При окончании удаляются только специальные группы тест-драйва и восемь групп «Модуль.Тестовый период».
  • Группа «Использовал тестовый период» добавляется обязательно.
  • В виджете активный период можно закрыть досрочно кнопкой «Забрать тестовый период»; команда сохраняется в той же долговечной очереди.
  • Неудачная выдача или отзыв повторяются с задержкой до подтверждения GetCourse; оплаченные группы не затрагиваются.

Для публичной формы подключите https://junior.sobakovod.pro/streams/testdrive/client.js и серверное подтверждение /streams/testdrive/confirm. Ключ подтверждения нельзя помещать в публичный JavaScript.

Массовый процесс GetCourse может передать всех пользователей из групп «Тест-драйв. Щенок» или «Тест-драйв. Собака». Callback быстро сохраняет каждый ID в постоянную очередь, а браузерная проверка выполняется строго по одному пользователю. Повторный вызов с тем же ID не создаёт дубль. Если ранее использованному пользователю снова открылись тестовые группы, Nexus ставит их снятие в очередь.

Кеш доступов

Один авторизованный браузер GetCourse последовательно обновляет снимки учеников. Запросы выполняются по одному, с плавающей задержкой и автоматической паузой при лимите, капче или потере сессии. Снимки используются Streams и виджетом переписок.

Данные

Runtime data/ хранит реестр, прогресс, операторов, тестовые периоды, снимки доступов и журнал операций и не включается в архив модуля.
