Управление потоками

Рабочий адрес: https://junior.sobakovod.pro/streams/. Для входа используется личная учётная запись Nexus; одного имени сотрудника недостаточно.

Потоки

  • Поток активируется только после появления VK- и Telegram-ссылок в таблице ссылок.
  • Учитель и дата берутся из операции создания чатов.
  • Новые подходящие оплаченные заказы назначаются в последний активный поток курса.

Google Sheets

Таблица учеников является зеркалом Nexus. Ручные изменения строк восстанавливаются. Обратно импортируются только чекбоксы уроков.

Перенос

GetCourse обновляется, ссылки отправляются через доступный канал, затем ученик удаляется из управляемых старых чатов. Неуправляемая VK-беседа пропускается без попытки удаления.

Данные

Runtime data/ хранит реестр, прогресс, операторов и журнал операций и не включается в архив модуля.
