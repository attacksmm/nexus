Senler → Telegram Events

Модуль принимает Telegram Update, которые Senler проксирует от подключённого бота, сохраняет полный JSON и формирует понятное описание каждого события.

Подключение

  1. Откройте вкладку Источники и создайте источник для бота.
  2. Скопируйте URL, имя заголовка X-Nexus-Senler-Secret и одноразовый секрет.
  3. В Senler откройте Telegram → Настройки → Проксирование → Серверы.
  4. Добавьте сервер, вставьте URL и добавьте пользовательский заголовок с выданным секретом.
  5. Активируйте сервер и отправьте сообщение боту. Событие появится в ленте Nexus обычно в течение пяти секунд.

Секрет показывается только при создании или перевыпуске. Nexus хранит только криптографический хеш. После перевыпуска старое значение перестаёт работать немедленно.

Webhook

POST https://junior.sobakovod.pro/nexus/senler-telegram-events/api/webhook/{source_uuid}
X-Nexus-Senler-Secret: {secret}
Content-Type: application/json

{ "update_id": 123, "message": { ... } }

После сохранения модуль отвечает HTTP 200. Повтор того же update_id не создаёт вторую строку: в существующем событии увеличивается счётчик повторов.

Что отображается

Версия 1.1 явно распознаёт все 26 верхнеуровневых типов Update из Telegram Bot API 10.2: сообщения и их изменения, каналы, Telegram Business, реакции, inline-режим, callback-кнопки, платежи, опросы, изменения участников, заявки, бусты, управляемых ботов и подписки.

ТипПример описания

МедиаФото, видео, документ, голосовое сообщение, стикер, геопозиция и подпись
CallbackНажатие кнопки от @username: callback_data

Хранение и приватность

  • По умолчанию события и полный JSON хранятся 30 дней.
  • Срок можно изменить от 1 до 365 дней.
  • Медиафайлы не скачиваются: сохраняются только данные Update, включая Telegram file_id.
  • Секретный заголовок не записывается в БД, интерфейс или модульный лог.
  • Панель и административные API доступны только администраторам Nexus.

Ответы и ошибки

  • 200 — событие сохранено, является повтором, невалидно или источник выключен.
  • 401 — неверный секрет; проверьте пользовательский заголовок в Senler.
  • 404 — источник удалён или URL указан неверно.
  • JSON больше 5 МБ фиксируется как отклонённый, без сохранения тела.

Версия 1.1 только принимает и показывает события. Она не отвечает пользователям и не пересылает Update в другие системы. Если Telegram добавит новый тип раньше обновления модуля, событие всё равно попадёт в журнал как неизвестное с полным исходным JSON.
