amoCRM → DB v1.0.3

Модуль принимает webhook amoCRM по сделкам, догружает актуальные данные сделки через amoCRM API и сохраняет snapshot в customer-db таблицу amo_deals с названием «Сделки amoCRM». Дополнительно модуль регулярно сверяет последние дни amoCRM с локальной БД и подтягивает сделки, если webhook был пропущен.

ENV

ПеременнаяОписание

AMO_ACCESS_TOKENТокен с доступом к сделкам, контактам и воронкам.

Webhook

URL берется во вкладке «Webhook». Если задан секрет, amoCRM должна отправлять запрос на URL с ?secret=.... Модуль принимает стандартный application/x-www-form-urlencoded формат amoCRM и JSON для ручного теста.

POST /nexus/amocrm-db/api/webhook?secret=...
leads[status][0][id]=123456
leads[status][0][pipeline_id]=111
leads[status][0][status_id]=142

Ответ для amoCRM всегда HTTP 200, чтобы amoCRM не отключала webhook при временной ошибке обработки. Ошибки фиксируются во вкладке «События».

Reconcile

Автосверка включена по умолчанию. Она периодически читает сделки amoCRM по created_at за последние дни, сравнивает deal_id с cdb_amo_deals.platform_id и синхронизирует отсутствующие записи. Параметры доступны во вкладке «Настройки»: включение, lookback в днях, интервал и задержка между синхронизациями. Ручной запуск выполняется кнопкой «Сверить сейчас».

Защита от 429 и потери webhook

Webhook сначала фиксируется в SQLite-очереди и только затем обрабатывается одним последовательным worker. Все запросы этого модуля к amoCRM проходят через общий ограничитель частоты. При HTTP 429 учитывается заголовок Retry-After, выполняются быстрые повторы, а если лимит сохраняется — событие остаётся в надёжной очереди с увеличивающейся задержкой и восстанавливается после перезапуска Nexus. Более новый webhook одной сделки заменяет только ещё не начатый старый webhook; актуальный snapshot не теряется.

Что сохраняется

Ключ записи в Базе клиентов: platform_id = deal_id. В custom_fields сохраняются сумма, воронка, статус, ответственный, даты, теги, контакты, телефоны, email, UTM, yclid, ym_uid, кастомные поля, raw snapshot сделки, ссылка на amoCRM и служебные поля синхронизации.
