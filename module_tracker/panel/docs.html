Трекер

Модуль собирает визиты, UTM, click id, IP/Geo, устройство и подтвержденные формы. Скрипт не меняет страницу: не правит URL, DOM, стили, формы и не блокирует отправку.

Tilda: строгая установка через T972

  1. Добавьте блок T972 на каждую страницу, включите «Принять все», «Отклонить все», настройки категорий и ссылку повторного открытия #opencookiebanner.
  2. Метрику/GA/GTM подключайте только через «Настройки сайта → Аналитика», чтобы ими управлял T972. Удалите дубли этих счетчиков из Head.
  3. Во вкладке «Скрипт» оставьте режим «Tilda T972 · строгий», скопируйте snippet и поставьте его самым первым кодом в Head.
  4. Любой свой inline-код аналитики делайте неисполняемым до согласия: type="text/plain" data-tilda-cookie-type="analytics". Рекламные пиксели используют категорию advertising.
  5. У внешнего файла заменяйте src на data-src. Удалите metric-pixel из noscript: при отключенном JavaScript получить согласие невозможно.
<!-- Аналитика / POST-трекинг -->
<script type="text/plain" data-tilda-cookie-type="analytics">
  // fetch(...) или inline-код счетчика
</script>

<!-- Рекламный пиксель VK -->
<script type="text/plain" data-tilda-cookie-type="advertising">
  // загрузка openapi.js и VK.Retargeting.Hit()
</script>

<!-- Внешний Nexus tracker -->
<script data-src="https://junior.sobakovod.pro/nexus/tracker/api/script.js"
  data-tilda-cookie-type="analytics" data-site="sobakovod"
  data-consent="managed"></script>

Inline gate не обращается к Nexus и не записывает cookie: он запускается с самой страницы Tilda, поэтому T972 и выбор категорий остаются доступны даже при блокировке junior.sobakovod.pro. До разрешения он дополнительно удерживает внутренний tilda-stat и известные прямые транспорты Метрики, Mail.ru, Senler и рекламных пикселей. Это закрывает отличие T972: штатная внутренняя статистика Tilda до выбора считает обезличенный переход без cookie.

Sobakovod: замена текущего Head

Текущий ручной Mail.ru-блок удалите целиком вместе с noscript: этот же счетчик уже подключен через настройки Tilda, иначе после согласия получится двойной просмотр. После strict snippet оставьте только размеченные VK и Senler:

t.src="https://vk.com/js/api/openapi.js?173";
t.onload=function(){VK.Retargeting.Init("VK-RTRG-1970487-gNb2D");VK.Retargeting.Hit()};
document.head.appendChild(t)}();
</script>

У VK и Mail.ru не должно остаться noscript img. Встроенные Яндекс.Метрика и Mail.ru остаются в настройках сайта и будут управляться T972; Nexus Tracker уже включен в strict snippet.

Защита от случайной ранней загрузки

data-consent="managed" запрещает Nexus Tracker создавать visitor/visit cookie, localStorage и сетевые события, пока inline gate не получил от T972 разрешение категории analytics. Даже ошибочный обычный src не включает сбор. Новые сторонние скрипты всё равно нужно явно относить к analytics, advertising или custom: автоматически и безошибочно определить назначение произвольного будущего кода невозможно.

data-site нужен только для группировки сайтов в панели. После согласия скрипт читает first-party _ym_uid, если его уже поставила Метрика.

Обычный сайт без T972

Для не-Tilda сайта остается автономный режим data-consent="required" data-banner="1". В строгой конфигурации не используйте data-auto-consent: скролл или продолжение просмотра не заменяют явный выбор.

window.NexusTracker.grantConsent("site_banner");
window.NexusTracker.revokeConsent();
window.NexusTracker.hasConsent();

Диагностика UTM

Вкладка UTM показывает, почему в источниках много (none): события без utm_source, страницы без разметки, click id без source и вероятные перестановки UTM-полей. Колонка «Оригинал» всегда показывает фактические значения, которые пришли в событии.

Поиск профилей

Поиск во вкладке «Люди» проверяет контакты, имя, visit/visitor id, IP, GeoIP город/страну, browser/device, fingerprint, host/referrer/URL, все UTM-поля, внешние id вроде _ym_uid/yclid и сохраненные значения форм/сырых событий.

Подтверждение формы

Автоматически срабатывают success URL и видимые success-блоки Tilda/GetCourse-подобных форм. Для SPA можно вызвать:

window.NexusTracker.confirmForm(document.querySelector("form"), { confirmation_reason: "crm_success" });

Хранение

Raw-события чистятся вручную во вкладке «Настройки» по retention, по умолчанию 6 месяцев. Склеенные профили людей остаются в БД модуля и синхронизируются в customer-db таблицу visitor_profiles.
