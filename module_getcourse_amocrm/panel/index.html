Связка

Можно выбрать сотрудника только для этой связки или оставить общую очередь.
Фиксированные правила: заказы «Автооплата» работают по полной связке. Для остальных заказов новая сделка не создаётся: по точному телефону находится контакт, а примечание добавляется во все его сделки, включая upsell. Поля, цены, статусы, названия, теги и ответственные не меняются. Созданная неоплаченная автооплата объединяется с последней неоплаченной попыткой по телефону; частичная и полная автооплата ищутся только по № ГК.
Поля и примечание обновляются всегда. Статус меняется только если текущий статус выбран здесь. Успешную сделку другого заказа модуль никогда не двигает.
Сначала проверяется № ГК в выбранной воронке, затем автоматически телефон контакта.
