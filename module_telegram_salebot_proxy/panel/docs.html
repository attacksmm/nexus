Nexus module · 1.0.3

Telegram → SaleBot Proxy

Модуль делает Nexus единственным Telegram webhook и пересылает исходный Update в ранее обнаруженный приёмник SaleBot.

Telegram→Nexus→SaleBot

Быстрое подключение

  1. Добавьте бота в панели модуля и вставьте актуальный token из BotFather.
  2. Нажмите «Начать ожидание».
  3. Подключите тот же token в SaleBot. Nexus опрашивает getWebhookInfo каждые пять секунд.
  4. После обнаружения канала вставьте API-ключ этого SaleBot-проекта. Nexus проверит, что в проекте подключён тот же username бота.
  5. Nexus включает long polling через глобальный Telegram proxy и передаёт сообщения в официальный SaleBot tg_callback.
  6. Напишите тестовое сообщение боту и убедитесь, что событие получило статус «Доставлено».

Если бот уже подключён к SaleBot до добавления в Nexus, его webhook будет найден сразу. Рабочий webhook не меняется до отдельного включения ожидания или кнопки «Включить прокси».

Telegram API не раскрывает ранее установленный secret_token, а внутренний SaleBot tg_webhook не является публичным relay API. Поэтому надёжный режим использует deleteWebhook(drop_pending_updates=false), getUpdates через глобальный Bot API proxy и поддерживаемый SaleBot tg_callback.

Безопасность

  • Bot token и полный URL SaleBot шифруются ключом, производным от NEXUS_SECRET.
  • Панель и управляющее API доступны только администратору Nexus.
  • Автоматически принимаются только HTTPS-приёмники домена salebot.pro и его поддоменов.
  • Telegram-запрос проверяется одновременно по случайному секрету в URL и заголовку X-Telegram-Bot-Api-Secret-Token.
  • Тело успешно доставленного Update удаляется из журнала. Для ошибок оно временно хранится, чтобы разрешить повтор.
  • Команда отката возвращает прямой SaleBot webhook с drop_pending_updates=false.

Переменные окружения

NEXUS_SECRET=стабильный-длинный-секрет
TG_SALEBOT_PROXY_PUBLIC_BASE=https://junior.sobakovod.pro/nexus

Доступ к Telegram Bot API всегда использует глобальный маршрут из Nexus → Настройки → Telegram. Прямое подключение модуля к api.telegram.org не применяется.

NEXUS_SECRET нельзя менять после добавления ботов: старые зашифрованные значения перестанут открываться. Если секрет всё же изменён, повторно введите bot token.

Доставка и повтор

Nexus передаёт SaleBot исходное JSON-тело без преобразования и возвращает Telegram HTTP-ответ SaleBot. При сетевой ошибке или не-2xx ответе Telegram повторит Update. Модуль также сохраняет неуспешное тело и позволяет выполнить ручной повтор из журнала. Повтор одного уже доставленного update_id подтверждается без второй отправки.

Ограничения

  • У Telegram может быть только один активный webhook на один bot token.
  • Telegram не показывает установленный ранее secret_token. Поэтому модуль совместим со стандартной схемой SaleBot, где секрет находится в URL, но после первого подключения требуется реальное тестовое сообщение.
  • Если SaleBot начнёт постоянно перезаписывать webhook, получится конфликт владельцев. Автовосстановление можно выключить, затем выполнить откат.
  • Переадресации upstream не выполняются: SaleBot должен отвечать напрямую с HTTP 2xx.

Аварийный откат

Откройте «Настройки бота» и нажмите «Откатить». Если Nexus недоступен, установите сохранённый SaleBot URL через Telegram setWebhook. Полный URL намеренно не отображается в панели; перед production-активацией храните резервную конфигурацию сервера.
