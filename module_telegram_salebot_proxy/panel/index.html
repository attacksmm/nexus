Токен проверен

Nexus проверяет бота через официальный Telegram Bot API и сохраняет токен в зашифрованном виде.

2

Подключите бота в SaleBot

Нажмите «Начать ожидание», затем вставьте этот же токен в SaleBot. Nexus автоматически распознает его webhook после двух проверок.

3

Подключите SaleBot API

Нужен API-ключ именно того SaleBot-проекта, где подключён этот Telegram-бот. Nexus проверит совпадение канала и сохранит ключ зашифрованно.

4

Включите прокси

Nexus забирает Telegram Update через глобальный Bot API proxy и передаёт сообщение в официальный SaleBot tg_callback.

Журнал доставки

Тексты сообщений не показываются. Тело успешно доставленного события сразу удаляется из базы.

Вернуть прямое подключение SaleBot

Telegram снова будет отправлять обновления напрямую в сохранённый SaleBot URL. Ожидающие сообщения не удаляются.

Удалить из Nexus

Доступно только после отката или до включения прокси.

Общие настройки

Публичный адрес используется при регистрации webhook в Telegram. Менять его при активном прокси нельзя.

Внутренний tg_webhook SaleBot не является публичным relay API и защищён скрытым Telegram secret. Для надёжной прокси-доставки используется официальный tg_callback с API-ключом конкретного проекта.

Добавить Telegram-бота

Вставьте токен из BotFather. Он отправляется только Telegram API и сохраняется зашифрованно.
