GetCourse → Пользователи

Модуль принимает callback процесса GetCourse и выполняет idempotent upsert в cdb_getcourse_users. Ключ строки — неизменяемый ID пользователя GetCourse.

Поток данных

Новая регистрация GetCourse → процесс «Пользователи» → «Вызвать URL» → этот модуль → Customer DB → «Конверсии»

Что передаётся

ID, email, телефон, имя, город, дата регистрации, UTM, SaleBot/VK/Telegram/Yandex IDs. Пустые значения не затирают ранее сохранённые поля, потому что Customer DB объединяет поля при upsert.

Настройка

Откройте основную панель модуля и скопируйте всю готовую GET-ссылку в операцию «Вызвать URL» процесса по пользователям. GetCourse подставит значения объекта в query-параметры ссылки; отдельные заголовки и тело запроса не нужны.

Безопасность

Секрет callback генерируется при первой установке, хранится в SQLite модуля и уже включён в готовую GET-ссылку. Без верного секрета endpoint отвечает как несуществующий. Доступ к ссылке настройки требует авторизации Nexus.

API

GET  /getcourse-users/api/health
GET  /getcourse-users/api/config       # авторизация Nexus
GET  /getcourse-users/api/webhook

CSV нужен только для разового восстановления истории. Текущие регистрации должны приходить через процесс.
