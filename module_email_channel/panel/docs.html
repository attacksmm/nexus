Email-канал Nexus

Модуль хранит цепочки, принимает ответы Даша.Роутер и отправляет персональные письма через transactional API DashaMail.

DNS

support.sobakovod.pro. TXT v=spf1 include:_spf.dashasender.ru ~all
dm2._domainkey.support.sobakovod.pro. TXT (DKIM DashaMail)
support.sobakovod.pro. MX 10 mta.dashasender.ru.

Персональные отправители

Адрес сотрудника один раз создаётся в формате имя.фамилия@support.sobakovod.pro и закрепляется за его ID. Боевой тест Email Transport подтвердил отправку и доставку с нового локального адреса внутри активного домена; отдельные DNS-записи и ящики не нужны. Резервный info@… используется только для неизвестного или вручную отключённого сотрудника.

Оформление и отписка

Ручные письма Nexus получают единый HTML-шаблон клуба, текстовую альтернативу и подпись сотрудника. Ссылка отписки сначала показывает подтверждение; изменение выполняется только после POST. Однокликовая отписка почтового клиента использует подписанный адрес и List-Unsubscribe-Post. Отписка блокирует только ручной email-канал Nexus и не отключает системные письма GetCourse.

Секреты

API key, transactional webhook key и Router signing key задаются в Credentials/ENV. Они не сохраняются в SQLite и не входят в архив.

Webhook URL

https://junior.sobakovod.pro/nexus/email-channel/api/webhooks/dashamail/events
https://junior.sobakovod.pro/nexus/email-channel/api/webhooks/dashamail/inbound

В Router используйте адреса case+…@support.sobakovod.pro, передачу вложений через URL и режим хранения как резерв.

Безопасность привязки

Главный идентификатор — непрозрачный токен в Reply-To. По похожему имени письмо никогда не связывается. Неоднозначные письма остаются в очереди ручного сопоставления.
