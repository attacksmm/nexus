Bizon365 отчеты

Модуль принимает webhook Bizon365 после создания отчета, объединяет повторные входы, сохраняет клиентов и отдельные посещения в customer-db и публикует feed для downstream-модулей. Пересылка в Vakas оставлена только для теневого переезда.

Webhook

GET /nexus/bizon-reports/api/webhook?secret=...&webinarId=...
POST /nexus/bizon-reports/api/webhook?secret=...&url=https%3A%2F%2Fvakas-tools.ru%2Fbase%2Freport%2F...

GET нужен для вставки готовой ссылки в Bizon365. Если параметр url не задан, модуль только сохранит клиентов в лист Клиенты Bizon365 и не будет пересылать запрос в Vakas. Если url задан, он должен начинаться с https://vakas-tools.ru/base/report/.

Настройки в панели

  • Webhook secret - входной секрет для Bizon365 webhook, хранится в базе модуля.
  • Bizon365 API token и Project ID - используются для API v2, если Bizon присылает только webinarId.
  • Timeout - общий таймаут запросов к Bizon API, customer-db и Vakas.

Отчеты Bizon365

Вкладка Отчеты Bizon365 получает список отчетов через Bizon API v2 /api/v2/{projectId}/reports/getlist. Кнопка Добавить или Перезагрузить забирает зрителей через getviewers и пишет обе проекции без пересылки в Vakas.

Customer DB

Модуль создает таблицу bizon365_clients с актуальной карточкой клиента и bizon365_attendance с отдельным фактом «человек + webinarId». Повторная доставка обновляет тот же attendance_key, а новый вебинар не перезаписывает историю.

Attendance feed

GET /nexus/bizon-reports/api/attendance-feed?after=0&limit=200
Authorization: Bearer <feed token>

Feed использует монотонный change ID. Токен отображается только авторизованным пользователям Nexus в настройках модуля.

Расчет времени

Повторные профили объединяются по телефону, email, uid, sid или chatUserId. Время считается по объединению непересекающихся интервалов vi; при их отсутствии используется валидная разница viewTill-view. Отрицательные и чрезмерные значения помечаются ошибкой.

Источники зрителей

  • Если webhook уже содержит массив viewers, items, users или packed Bizon report.usersMeta, модуль берет зрителей из webhook.
  • Если зрителей нет, но есть webinarId, модуль вызывает Bizon API v2 /api/v2/{projectId}/reports/getviewers с заголовком X-Token: BIZON365_API_TOKEN.
  • Если нет ни зрителей, ни API token, raw webhook все равно сохраняется и пересылается в Vakas.

ENV

  • Дополнительные ENV вручную не требуются: секрет webhook и Bizon token задаются во вкладке Настройки.
  • Customer DB и внутренний адрес Nexus модуль определяет автоматически внутри Nexus.
