GetCourse → Wazzup

Самодостаточный коннектор: сотрудники, каналы и переписка Wazzup прямо из GetCourse.

Что делает модуль

Скрипт находит телефон в карточке GetCourse и добавляет кнопку «Написать через Wazzup». Сотрудник выбирает активный канал, после чего читает историю и отвечает в собственном чате Nexus. При первом открытии модуль создаёт ограниченную сессию штатного iframe Wazzup и только на чтение импортирует до 500 сообщений найденного диалога; затем новые сообщения и статусы поступают через webhook.

Чтение истории использует внутренний интерфейс штатной iframe-сессии Wazzup, потому что публичный CRM API v3 не предоставляет метод истории. Если Wazzup изменит внутренний контракт, новые сообщения продолжат работать через официальный webhook, а старую историю можно открыть действием «Открыть Wazzup».

Сотрудники создаются в Wazzup из вкладки «Сотрудники» GetCourse. Официальный API GetCourse не отдаёт перечень сотрудников, поэтому виджет читает видимую таблицу этой штатной страницы; за один запуск — до 100 строк.

Проверка без GetCourse

Нажмите «Тестовая карточка» в верхней панели модуля. Откроется защищённая страница, имитирующая карточку пользователя GetCourse и загружающая тот же widget.js. Можно менять тестовые имя и телефон, проверять появление кнопки, одноразовую активацию и открытие Wazzup.

Тестовый режим доступен только авторизованному администратору Nexus. Активация хранится в домене Nexus и не переносится в GetCourse: после установки скрипта сотрудник один раз активирует браузер уже на домене GetCourse.

Подключение

  1. В Wazzup откройте «Интеграция с CRM → API» и скопируйте обычный API key, не ключ Sidecar.
  2. В Nexus сохраните ключ, нажмите «Проверить связь», затем «Подключить webhook».
  3. Во вкладке «Администраторы» нажмите «Добавить» и создайте себя в Wazzup. Затем создайте себе одноразовый код.
  4. Скопируйте HTML-код из вкладки «Подключение» в общий HTML-блок GetCourse. Откройте любую карточку и активируйте браузер своим кодом.
  5. Откройте GetCourse: «Пользователи → Сотрудники», нажмите «Синхронизировать сотрудников с Wazzup». Повторите на следующих страницах списка, если сотрудников больше 100.

Где появляется кнопка

Кнопка чата работает в карточках:

/user/control/user/update/id/{id}
/sales/control/deal/update/id/{id}

На странице /user/control/user виджет показывает кнопку синхронизации сотрудников. Телефон в карточке ищется сначала в стандартном элементе .user-call-to-phone, затем в ссылках tel: и известных полях. Российские номера нормализуются к формату +7….

Администраторы и устройства

Каждый администратор связан с отдельным пользователем Wazzup. Код активации одноразовый и живёт 15 минут. После активации браузер получает случайный токен на 180 дней; срок продлевается при использовании. Доступ можно отозвать во вкладке «Устройства». Выключение администратора отзывает все его устройства.

Безопасность

  • API key Wazzup хранится только в ENV Nexus и никогда не попадает в браузер.
  • Методы виджета принимают запросы только с https://club.sobakovod.pro и требуют токен активированного устройства.
  • Webhook использует непредсказуемый секрет в URL, зарегистрированный сервером непосредственно в Wazzup.
  • В базе лежат SHA-256 хэши кодов, токенов и телефонов для сопоставления; тексты сообщений сохраняются для отображения переписки.
  • Отправка невозможна без явного пользовательского нажатия «Отправить»; тесты используют mock и не обращаются к живому методу отправки.
  • Одноразовая iframe-ссылка и API key никогда не записываются в журнал.

Если панель не открывается

  • «Требуется повторная активация» — устройство отозвано или истёк срок. Создайте новый код.
  • «Wazzup API key не настроен» — сохраните ключ в Nexus.
  • Ошибка Wazzup HTTP — проверьте ключ кнопкой «Проверить связь».
  • Телефон не найден — откройте карточку с заполненным номером; без номера невозможно выбрать чат.
  • На странице сотрудников нет кнопки — сначала активируйте браузер на любой карточке GetCourse.
