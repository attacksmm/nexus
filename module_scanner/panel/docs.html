Сканер

Модуль проверяет VK messages.getConversations с фильтром unanswered и сохраняет события локально. Его очередь теперь отображается в единой панели Общение с администрацией; сам Scanner скрыт из основной навигации, но остаётся самостоятельным детектором и владельцем API.

Очереди

  • Не отвечено — входящие, где после SLA не найден OpenRouter/Senler-ответ или ручной ответ ОП.
  • Общение с админом — входящие из VK unanswered, перед которыми в этот же московский день уже было исходящее сообщение админа.

При открытии клиента кнопкой VK модуль помечает все активные события этого VK ID прочитанными. VK-алерты в чаты не отправляются.

API

GET /nexus/scanner/api/events?tab=problems&unread=1&limit=20
POST /nexus/scanner/api/scan
POST /nexus/scanner/api/events/{id}/open
GET /nexus/scanner/api/env-status
