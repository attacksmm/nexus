Порядок запуска

  1. Укажите домен GetCourse и API key Wazzup.
  2. Проверьте связь и подключите webhook.
  3. Добавьте сотрудников.
  4. Сопоставьте аккаунты.
  5. Создайте коды активации.
  6. Установите код виджета в GetCourse.
