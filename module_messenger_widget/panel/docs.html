Виджет мессенжеров

Wazzup, VK и Telegram Personal в карточках GetCourse и amoCRM.

Что делает интеграция

Кнопка «Написать» открывает каналы Wazzup, Telegram Personal и подключённое сообщество VK для контакта текущей карточки. Недоступные каналы остаются видимыми, но неактивными. Диалоги, история, изображения и файлы доступны в одном окне.

Обе CRM используют общую базу диалогов и шаблонов. Личные шаблоны видит только менеджер, общие — все сотрудники. В списке диалогов работает поиск по имени, телефону и идентификаторам, а каналы можно скрыть фильтром.

Сначала загружаются 12 последних сообщений. Более ранние подгружаются при прокрутке вверх.

Тестовые карточки

Нажмите «Тестовая карточка» и выберите GetCourse или amoCRM. Тестовые имя, телефон, email и идентификаторы передаются в рабочий API: доступны подключённые каналы, история, шаблоны и отправка.

Для GetCourse и amoCRM используется отдельная активация. Отправленные сообщения настоящие.

Подключение

  1. Укажите корневые HTTPS-домены GetCourse и amoCRM.
  2. В Wazzup откройте «Интеграция с CRM → API» и скопируйте API key.
  3. Сохраните настройки, проверьте связь и подключите webhook.
  4. Добавьте сотрудников и создайте одноразовые коды.
  5. Установите HTML-код в GetCourse.
  6. Скачайте архив amoCRM и установите его как приватную интеграцию.

Идентификаторы

Индекс связей читает модуль «База данных» только для поиска и хранит компактный дисковый индекс рядом с рабочей БД модуля. Точные телефон, email, GetCourse ID, VK ID, Telegram ID, platform_id и salebot_id объединяют аккаунты. platform_id используется как Telegram ID, если отдельный Telegram ID не найден; salebot_id подключает переменные связанного аккаунта. Неоднозначный utm_term применяется только когда найден ровно один связанный тип.

Шаблоны и переменные

Перед отправкой сервер подставляет переменные и блокирует сообщение, если остались конструкции {{...}}. Основные переменные: {{contact.name}}, {{contact.phone}}, {{manager.name}}, {{utm.source}}, {{utm.campaign}}, {{utm.term}}, а также поля пространств getcourse.*, getcourse.order.*, amo.lead.*, vk.* и telegram.*.

VK

  1. Создайте ключ сообщества с доступом к сообщениям.
  2. Укажите ID сообщества и ключ.
  3. Нажмите «Проверить», затем «Подключить».
  4. Нажмите «Синхронизировать» для загрузки текущих диалогов.

VK появляется в карточке при точной связи VK ID с GetCourse ID. Виджет читает ссылку VK из профиля GetCourse; готовые связи можно подключить через SYNC_CONTROL_DB.

Telegram Personal

Модуль использует авторизованную Telegram-сессию Nexus. Если сессии нет, укажите телефон, получите код и войдите. При включённой 2FA введите пароль. Пароль не сохраняется.

Канал появляется в карточке при совпадении Telegram ID, platform_id, username или телефона с существующим диалогом. При открытии карточки точный телефон можно импортировать в авторизованный Telegram и начать диалог. По имени пользователи не связываются.

Где появляется кнопка

Инбокс работает на всех страницах GetCourse. Кнопка чата работает в карточках:

/user/control/user/update/id/{id}
/sales/control/deal/update/id/{id}

На странице /user/control/user виджет показывает кнопку синхронизации сотрудников. Телефон в карточке ищется сначала в стандартном элементе .user-call-to-phone, затем в ссылках tel: и известных полях. Российские номера нормализуются к формату +7….

Сотрудники и устройства

Сотрудник сопоставляется с аккаунтами GetCourse и amoCRM через списки в панели. Роль «Сотрудник» показывает только закреплённых клиентов; роль «Администратор» — все диалоги. Код активации одноразовый и живёт 15 минут. После активации браузер получает токен на 180 дней; доступ можно отозвать во вкладке «Устройства».

Безопасность

  • API key Wazzup хранится только на сервере.
  • Запросы GetCourse и amoCRM принимаются с настроенных доменов и требуют токен активированного устройства.
  • Токен amoCRM связан с ID пользователя amoCRM.
  • Чувствительные поля не становятся переменными шаблонов.
  • Одноразовая iframe-ссылка и API key не записываются в журнал.

Если панель не открывается

  • «Требуется повторная активация» — устройство отозвано или истёк срок. Создайте новый код.
  • «Wazzup API key не настроен» — сохраните ключ в панели подключения.
  • Ошибка Wazzup HTTP — проверьте ключ кнопкой «Проверить связь».
  • Телефон не найден — откройте карточку с заполненным номером; без номера невозможно выбрать чат.
  • На странице сотрудников нет кнопки — сначала активируйте браузер на любой карточке GetCourse.
