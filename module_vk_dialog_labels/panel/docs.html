VK метки диалогов v1.0.0

Модуль принимает webhook amoCRM по сделкам, выбирает правило по статусу сделки, сохраняет целевую метку диалога во внутренней базе Nexus и применяет доступное официальное действие VK.

Ограничение VK API

В публичной схеме VK API 5.199 есть методы messages.markAsImportantConversation и messages.markAsAnsweredConversation. Публичного метода для назначения кастомных меток из интерфейса сообщений сообщества не найдено. Поэтому названия вроде Заказ, НА КУРСЕ или после Веба сохраняются в Nexus, а в VK применяются только официальные отметки.

Источник проверки: VKCOM/vk-api-schema.

Правила

Правило содержит тип события/статуса amoCRM, выбранные статусы, целевую метку Nexus и официальное действие VK:

  • none — только сохранить метку в Nexus;
  • important_on / important_off — поставить или снять важность диалога;
  • answered_on / answered_off — отметить диалог отвеченным или неотвеченным.

Тест

Тестовый endpoint ограничен одним диалогом:

https://vk.com/gim225075265/convo/1105209997

Любой другой peer_id или group_id отклоняется.
