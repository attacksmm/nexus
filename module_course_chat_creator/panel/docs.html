Создание учебных чатов

Назначение

Модуль переносит legacy endpoint'ы Sobakovod/Windsurf для создания учебных чатов в Nexus и добавляет панель управления списками людей, курсами, шаблонами и рассылками по обучающим чатам.

Публичные endpoint'ы

POST /nexus/course-chat-creator/api/vk/create
POST /nexus/course-chat-creator/api/telegram/create
POST /nexus/course-chat-creator/api/chats/create

Для старых сценариев оставлены алиасы /process_vk и /process6. Публичные webhook-вызовы требуют поле password, если задан NEXUS_CHAT_CREATOR_PASSWORD. Запуск из панели Nexus работает по авторизации Nexus. Документация открывается штатной кнопкой Nexus ? у модуля.

Поля запроса

{
  "password": "...",
  "stream_number": "51",
  "start_date": "01.06.2026",
  "date_start": "01.06.2026",
  "course_choice": "1",
  "course_type": "puppy",
  "curator_id": "2",
  "test_mode": "true"
}
  • course_choice=1 и course_type=puppy означают курс щенка.
  • course_choice=2 и course_type=dog означают основной курс собаки.
  • curator_id выбирает одного куратора из таблицы людей. Если поле не передано, по умолчанию выбирается активная Ирина, затем первый активный куратор.
  • Если дата не передана, модуль использует текущую дату Москвы. Панель устанавливает её при каждом открытии.
  • VK: test_mode=true создаёт чат без учеников, приглашает только аккаунт техподдержки и использует тестовый закреп.
  • VK: боевой режим добавляет доступных сотрудников. Покупатели получают ручную ссылку потока после активации пары VK+Telegram.
  • Telegram: test_mode=true создаёт пустой чат без приглашения людей, бота и назначения админов.

ENV

Минимально нужны только ключи ниже. Telegram session создаётся во вкладке Telegram внутри панели. Webhook password нужен только для внешних публичных вызовов.

VK_GROUP_TOKEN=
VK_GROUP_ID=
TELEGRAM_API_ID=
TELEGRAM_API_HASH=

Опционально: NEXUS_CHAT_CREATOR_PASSWORD или SBKVD_PROCESS_WEBHOOK_PASSWORD для webhook, VK_TEST_GROUP_TOKEN для тестового сообщества, TELEGRAM_SESSION_FILE и TELEGRAM_MTPROTO_PROXY_URL.

ВКонтакте

  • VK-чат создаётся официальным токеном сообщества. Право покупателя определяется обработанным заказом GetCourse; ручной лист учеников не блокирует создание и выдачу.
  • Клиентские VK/TG-ссылки берутся из таблицы 1zu1__XcKxJH8yC9ForDvibaUnKFCS1pxWHEjLgqlVXA. Nexus добавляет строку потока и Telegram-ссылку, сохраняет заполненные ссылки и оставляет VK-ссылку для ручного создания с показом последних 250 сообщений.
  • До выдачи ссылки модуль отправляет единое учебное сообщение с памяткой и закрепляет его по локальному идентификатору беседы VK.
  • В новых беседах, владельцем которых является сообщество, покупателю с известным VK ID модуль отправляет ручную ссылку потока, когда сообщения разрешены. Для старых бесед отправка от сообщества отключена.
  • Покупатели без VK ID получают ссылку на действующей странице чатов по телефону или ID.
  • Сотрудники открывают ссылку из истории запуска. После входа сотрудник автоматически получает права администратора.
  • Начальные участники получают учебное сообщение после добавления. Вошедшие по ссылке получают отдельное приветствие модератора; массовых приветствий нет.
  • Сотрудникам модуль автоматически выдаёт админку после входа по ссылке и проверяет роль.
  • Закреп обычного участника автоматически заменяется закрепом курса. Закреп администратора сохраняется до действия Вернуть закреп. Для старого раздельного закрепа это действие создаёт единое сообщение с памяткой и текстом.
  • Раздел Участники показывает записанные учебные VK-чаты, открывает их от сообщества, возвращает закреп курса и выполняет dry-run перед массовой выдачей админки, снятием роли или удалением участника.
  • Недоступные токену сообщества старые чаты показываются с ошибкой VK и не изменяются.
  • Пользовательский токен не используется.

Что сохраняется

  • VK: создание беседы от имени сообщества, аватар, приветствие, закреп и invite link.
  • Telegram: создание forum supergroup, обязательная проверка тем Инфо/Визитка/Обучение/Болталка, аватар из static/group_photo.jpg, бот, полные права администратора всем сотрудникам без anonymous, приветственные сообщения, закрепы, invite link.
  • Панель: редактирование и удаление людей, курсов, шаблонов, Telegram-авторизация, рассылки по учебным чатам, удаление людей только из учебных чатов и переход в созданные VK/Telegram-чаты из истории.
  • Шаблоны по умолчанию взяты из Windsurf/Sobakovod endpoint'ов.

Рассылки

Вкладка Рассылки ищет обучающие VK и Telegram чаты по названию вида N. DD.MM.YYYY - ..., объединяя live scan с историей runs. VK отправляет через VK_GROUP_TOKEN, Telegram — через текущую Telethon session.

  • Можно выбрать конкретные чаты или отправить во все найденные, сняв лишние.
  • Telegram-рассылка отправляется в главный чат, не в forum topic.
  • Удаление доступно только для сообщений, которые были отправлены этой вкладкой и сохранены в истории рассылок.
  • Если токен или session не могут отправлять в чат, строка показывается как недоступная и не выбирается.

Люди

Для сотрудника указываются имя, роль, VK страница/username/ID и Telegram username. В текстах приветствия используются username, не телефоны. Текущий базовый состав: Анна — автор курса, Ирина — куратор, остальные сотрудники — админы без отдельной видимой подписи администратора.

Удаление

Вкладка удаления сначала показывает dry-run. Реальное удаление применяется только к чатам с названием потока вида 51. 01.06.2026 - ... и курсом Собаковода.
