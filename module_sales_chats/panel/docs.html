Модуль «Чаты продаж»

Единый рабочий чат для отдела продаж. Список людей берётся из разрешённых листов customer-db, сообщения отправляются через те же VK и Telegram токены, что использует модуль «Рассылки».

Администрирование

  1. Во вкладке «Люди» добавьте логины для fullscreen-чата. Вход без пароля, как в sbkvd-gpt.
  2. Во вкладке «Листы customer-db» выберите таблицы, канал и поле с ID получателя.
  3. Во вкладке «Общие шаблоны» настройте шаблоны, доступные всем пользователям fullscreen-чата.
  4. Откройте /nexus/sales-chats/panel/chat/ или кнопку «Открыть fullscreen».

Шаблоны и переменные

Личные шаблоны пользователь настраивает в fullscreen-чате через кнопку «Мои шаблоны». Общие шаблоны настраиваются администратором в модуле. Переменные подставляются из карточки customer-db при вставке и повторно перед отправкой.

{name}
{first_name}
{platform_id}
{utm_source}
{utm_medium}
{utm_campaign}
{utm_content}
{utm_term}
{yclid}
{ym_uid}
{url.utm_source}
{url.yclid}

Префикс url. кодирует значение для ссылки. UTM-поля, yclid и ym_uid можно писать коротко, модуль найдёт их внутри utms в customer-db.

Telegram

Модуль не вызывает getUpdates и не меняет webhook Telegram-бота, чтобы не ломать текущую Salebot-воронку. Отправка через Bot API доступна сразу, а входящие Telegram-сообщения можно передавать в модуль отдельным webhook из Salebot или другой интеграции.

POST /nexus/sales-chats/api/inbound/telegram?secret=...
Content-Type: application/json

{
  "chat_id": "123456789",
  "text": "Сообщение клиента",
  "message_id": "987",
  "name": "Имя клиента"
}

ENV

  • SBKVD_LETTER_VK_TOKEN — VK Community token.
  • SBKVD_LETTER_TELEGRAM_BOT_TOKEN — Telegram bot token.
  • SBKVD_LETTER_TELEGRAM_API_BASE и SBKVD_LETTER_TELEGRAM_PROXY_URL — необязательные настройки доступа к Bot API.
  • SALES_CHATS_CUSTOMER_DB_PATH — необязательный override пути customer-db.
  • SALES_CHATS_WEBHOOK_SECRET — необязательный секрет inbound webhook; если не задан, секрет создаётся в БД модуля.
