Токены

Основное управление перенесено в настройки Nexus → «Подключения». Панель модуля сохранена для совместимости.

Раздел VK ID использует Authorization Code с PKCE S256. Callback: /nexus/token-vault/api/vk/callback. Access token хранится как VK_USER_TOKEN; Refresh token, device_id и сроки действия хранятся в закрытом ENV Nexus.

Access token обновляется за 10 минут до истечения. VK ID меняет Refresh token при каждом обновлении, поэтому новая пара сохраняется атомарно. После неоднозначной сетевой ошибки автоматические повторы блокируются до повторной авторизации.

Запрашивайте только права, разрешённые в настройках приложения. VK не выдаёт право messages новым приложениям автоматически.

VK ID API

  • GET /api/vk-id/status — состояние без значений ключей.
  • POST /api/vk-id/config — сохранить ID, ключи и scope.
  • POST /api/vk-id/start — получить URL авторизации.
  • GET /api/vk/callback — публичный callback с проверкой state.
  • POST /api/vk-id/refresh — обновить токен вручную.

Поддерживаемые автоматические проверки: VK user token через users.get, VK message/community token через messages.getConversations, Telegram bot token через getMe, OpenRouter через /auth/key, Senler через базовый API-запрос при наличии SENLER_GROUP_ID.

Сохранение пишет значение в общий .env Nexus и применяет его к текущему процессу. Для сервисов, которые читают ENV только на старте, нужен перезапуск Nexus.

На телефоне выберите ключ в списке. Откроется редактор с кнопкой возврата к токенам. Сохранение без проверки требует подтверждения.
